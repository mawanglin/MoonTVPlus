# 飞牛 fpk 打包更新日志

每个版本对应 git tag `v<上游版本>-cob.<N>`，fpk 包内版本为 `<上游版本>.<N>`。
build.sh 取第一个 `##` 小节的条目作为应用中心里显示的更新说明。

## 227.0.1.3

- 修复：飞牛升级时会带着安装向导的旧值再执行一次安装脚本，可能把「应用设置」里改过的站长账号密码冲回安装时的值；现在升级时保留现有配置，只有「卸载时保留数据、再重新安装」才使用向导里新填的账号。

## 227.0.1.2

- 应用改为直接在安装目录运行，不再解压一份到数据目录，少占约 490 MB 磁盘、安装更快；升级时自动清理 227.0.1.1 留下的解压文件。
- 数据、日志目录的权限收紧为仅应用自己可读写（目录 750、文件 640），每次安装、升级、启动时都会检查。

## 227.0.1.1

- 首个飞牛原生版：基于上游 MoonTVPlus 227.0.1，内置 Node.js 24 与全部依赖，使用 SQLite 存储，不依赖 Docker。
